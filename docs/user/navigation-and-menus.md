# Navigation and menus

---

## Top navigation tabs

The main window uses tabs across the top:

| Page | Purpose |
|------|---------|
| **Library** | Song table, filters, playback |
| **Setlists** | Setlist folders, sets, set export, ABCP import/export |
| **Bands** | Bands, players, layout grids |
| **Set Play** | Bandleader live set control |
| **Band Assistant** | Connect to a leader's relay session |

**Settings** is not a main tab. Open it with **File → Settings…**.

---

## File menu

| Item | Action |
|------|--------|
| **Scan Library…** | Index ABC files from configured folders (includes duplicate review when needed) |
| **Write PluginData…** | Write Songbook data to enabled account targets |
| **Settings…** | Opens the Settings dialog |
| **Exit** | Quit the application |

---

## Help menu

| Item | Action |
|------|--------|
| **User Guide** | Opens this documentation |

---

## Playback bar

A persistent bar at the **bottom** of the main window controls playback: scrubber, tempo, transport, parts/playlist, stereo width, and volume.

See [Playback bar](playback.md).

---

## Unsaved changes

Some pages (Setlists, Bands) and Settings track unsaved edits. Switching away or closing the app may prompt you to save or discard changes.
