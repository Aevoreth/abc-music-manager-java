# Settings — ABC Playback

**File → Settings… → ABC Playback**

Defaults for the [playback bar](../playback.md).

---

## Soundfont path

Path to the `LotroInstruments.sf2` soundfont file. **Empty** uses automatic lookup (`%LOCALAPPDATA%\MaestroCommon`) or prompts to download.

- **Browse…** — pick a file
- Clear the field to use the default lookup

---

## Default volume

0–100

---

## Default tempo

0.5× to 2×.

---

## Stereo mode and width

| Mode | Behavior |
|------|----------|
| **maestro** | Maestro default panning |
| **maestro_user_pan** | Use user pan directives from ABC |
| **band_layout** | Pan from player positions on the active band layout |

**Stereo width** (0–100): **0 = mono**, **100 = full stereo**. Applies to multi-part songs.
