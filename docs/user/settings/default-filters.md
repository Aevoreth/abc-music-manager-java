# Settings — Library Filters

**File → Settings… → Library Filters**

Manage named presets for the [Library filters](../library.md#filters) pane.

**Default** is always present. It is applied when you open the app and when you click **Reset Filters**. It can be edited here, and overwritten from the Library pane, but it cannot be renamed or removed.

Other presets are optional. **Add** copies the preset you are editing, **Rename** and **Remove** apply to those extra names, and the fields on the right edit the selected preset. **Save** in Settings stores the whole list.

You can also create and overwrite presets from the Library filters pane with **Save To...** without opening Settings.

---

## When a preset applies

- **Default** — when you first open the app, when you click **Reset Filters**, or when you pick **Default** in the filters pane
- **None** — same as **Clear Filters** (show everything). **None** is not a saved preset
- Any other name — when you pick it in the filters pane

The Title / Composer box is not part of a preset. Choosing **None** or clicking **Clear Filters** clears it. Other presets leave that search text alone.

If you change the filters pane after loading a preset, the preset box shows `<- Modified ->` until you pick a preset again or save.

---

## Options

Each preset stores the filters pane:

- In set (Either / Yes / No)
- Rating range
- Duration min/max
- Last played (time or date range, including Never)
- Parts count min/max
- Status ids
- Transcriber names
